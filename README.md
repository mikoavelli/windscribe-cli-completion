# windscribe-completion

Tab completion for [Windscribe](https://windscribe.com/)'s command line
client, `windscribe-cli`, on Bash.

Status: early development. See [CHANGELOG.md](CHANGELOG.md) and the git
history for progress.

## Install

```sh
./install.sh
```

See the full README once the first release lands.
